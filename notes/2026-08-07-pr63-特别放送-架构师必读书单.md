李运华从每年读 50+ 本书里挑出的精选，分三类：

**成长篇**：《异类》《随机漫步的傻瓜》《一万小时天才理论》《情商》《优秀到不能被忽视》《影响力大师》。

**技术篇**：先给一个通用路径——深学运行环境（Linux/iOS/浏览器）→ 深学核心工具（Java/MySQL）→ 深学领域基础（网络/算法）→ 广学成熟技术（Netty/Spring/Redis）。以 Linux 后端 Java 为例推荐：《UNIX 编程艺术》《UNIX 网络编程卷 1》《UNIX 环境高级编程》《Linux 系统编程》《TCP/IP 详解卷 1》《算法之美》《算法设计与应用》《Java 编程思想》《深入理解 Java 虚拟机》《C++ Primer》。

**业务篇**：《增长黑客》《需求》《淘宝十年产品事》《定位》《宝洁制胜战略》——架构师要懂业务，「防止被产品经理坑」。

**立场**：技术篇的书单对 Java 后端就是标配，我读过其中大半，确实一本没踩雷；业务篇我之前完全忽视，《淘宝十年产品事》和《需求》该补——架构师不能只会画框图。收藏书单没意义，挑一两本消化掉比囤十本强。
